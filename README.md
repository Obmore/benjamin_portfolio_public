# Ott Benjámin – ottbenjamin.hu

Website of Ott Benjámin e.v. (sole proprietor, Hungary): custom websites and technical software, with fixed-price entry
packages. Hungarian only; the English imprint stays at `/en/imprint/`. Live at <https://ottbenjamin.hu> (GitHub Pages).

## Stack

- Vite + TypeScript; static HTML on GitHub Pages (`public/CNAME`).
- React **at build time only**: the pages are rendered to static HTML (`src/site/render.tsx`); the browser gets small
  scripts, never React.
- Playwright end-to-end tests with Axe, oxlint, Node's test runner for the build scripts.
- Node version: `.nvmrc`.

## Develop

```bash
npm ci
npm run dev        # http://localhost:5173/, the dev server renders the pages on request
npm run build      # preview build: open questions stay visible, marked [KÉRDÉS: …]
npm run preview
```

The page registry is `src/content/oldalak.ts`; the e2e page lists (`e2e/pages.ts`) are derived from it. Removed or renamed
URLs are one list, `src/content/atiranyitasok.ts`: the build writes a static redirect stub for each.

bundled with `?worker&url` and appended only where needed: **no shared chunk and no new head tag** (`check:static`
enforces the script list of every page, `scripts/lib/modul-szkriptek.mjs`).

## Rules the checks enforce

- **Prices have one source**, `src/data/pricing.ts`. Static pages use `{{huf:…}}` and `{{vat}}` placeholders; never type an
  amount into HTML or content (`e2e/customer-site.spec.ts`, `check:megrendeles`).
- **Colours are tokens.** Only `src/site/fooldal/jel-tokens.css` (Grafit, light and dark) holds colour literals; every
  other stylesheet uses `var(--…)`. `check:site` also limits hex colours in all other sources to the palette in
  `scripts/color-allowlist.json`.
- **Only real, sourced values** appear in a drawing or a number: each is a demo's own data or computation, with the file
  named at the value (`src/content/retegek.ts`, `sorozatok.ts`, `scripts/retegek-adatok.test.mjs`). The adventure world's samples
  (`src/content/mintak.ts`: the demo's 480-minute CNC-1 run and the client picture's block means) are generated by
  `scripts/mintak-epit.mjs` and recomputed by `scripts/mintak.test.mjs` and `e2e/mintak.spec.ts`.
- **Open questions** are written `kerdes('…')` in `src/content/` and show as `[KÉRDÉS: …]` in a preview build. The
  production build (`ELES_BUILD=1`, set by `deploy.yml`) fails if any built page still contains one
  (`scripts/lib/helyorzo-kapu.mjs`). A decision that the owner made about a value is recorded in the comment above that value; decisions that only remove a feature (see Other) are recorded here.
- **Motion** only inside `@media (prefers-reduced-motion: no-preference)`; the reduced form is opacity, colour or line
  drawing of at most 300 ms (`check:motion`, `scripts/lib/motion-rules.mjs`).
- **Page turns** use cross-document View Transitions, CSS only (`src/site/lapcsere.css`). The opt-in
  (`@view-transition`) is injected inline into every built `<head>` by `vite.config.ts` (`src/site/lapcsere-fej.ts`):
  in an external stylesheet it can arrive late and Chromium then logs an `InvalidStateError`.
- **Privacy:** the privacy notice has one source, `adatkezeles/index.html`; its reviewed article is fingerprinted in
  `docs/privacy-content.sha256` and compared with the built page by `check:privacy`.

## Verification

```bash
npm ci
npx playwright install chromium
npm run check      # lint (oxlint + tsc of the e2e specs), script tests, build, and the six build checks below
npm run test:e2e   # builds, serves with vite preview, runs Playwright (chromium)
```

| Check | What it guards |
| --- | --- |
| `check:size` | gzip budgets for JS and CSS, raw-size budgets for fonts and preloads (`scripts/check-budgets.mjs`) |
| `check:motion` | the motion rules above |
| `check:megrendeles` | the order page: money formatting, no hand-typed amounts, shared-layer markup |
| `check:static` | redirect stubs, the legal pages, each page's script list |
| `check:privacy` | privacy notice source equals the built page |
| `check:site` | sitemap, one contact address, page-turn opt-in, colours, third-party notices |

`e2e/support/mail-guard.ts` patches every browser context so that no spec can open the operating system's mail client
through a `mailto:` link.

`playwright.compat.config.ts` runs a fixed list of specs (`testMatch`, extended by hand) in Firefox and WebKit, inside the
official Playwright container whose image tag must match `@playwright/test` in `package-lock.json` (a guard step and
`scripts/e2e-matrix.test.mjs` check it). Locally it needs `npx playwright install firefox webkit`.

## CI

- `.github/workflows/verify.yml` (pull requests to `main`, manual): `verify` (`npm run check`), `e2e (chromium 1/2)` and
  `(2/2)`, `compatibility (firefox)`, `compatibility (webkit)`. Details and the reasons for the split are in the file.
- `.github/workflows/deploy.yml` (push to `main`, manual): production build with `ELES_BUILD=1`, deployed to GitHub Pages.
- `.github/workflows/claude-review.yml`: an automatic review of non-draft pull requests when they are opened, reopened or marked ready, and of any pull request that gets the `claude-review` label; needs the secret
  `CLAUDE_CODE_OAUTH_TOKEN`.

## Other

- **Fonts:** Archivo (variable) and Martian Mono 500, subsetted WOFF2 in `public/fonts/`, committed. Rebuild only after a
  font package update (needs Python 3 with fonttools and Brotli):
  `python -m pip install -r scripts/requirements-fonts.txt && npm run build:fonts`.
- **Analytics:** cookieless Umami Cloud (EU), configured in `ANALITIKA` in `src/content/beallitasok.ts` (`null` switches it
  off; the privacy notice must then be reverted too). `src/site/meres.ts` loads it only on `ottbenjamin.hu` and
  `www.ottbenjamin.hu`, and not when the visitor sends Do Not Track or Global Privacy Control. Any probe of the live site
  must set `globalPrivacyControl`, or it counts as a visitor.
- **Theme:** the system theme until the "Sötét mód" key is used; the choice is remembered in `localStorage` (`jel-tema`).
- **Third-party material and licences:** `docs/THIRD_PARTY.md`, served as `public/third-party-notices.txt`.
- **Owner decisions:** no CV, no phone number, no portrait yet, no capacity statement, Hungarian only.
- **Docs:** `docs/teendo-2027-01-01-mkik.md` (the registry authority changes from NAV to MKIK on 2027-01-01). The planning
  documents of the adventure world are not part of this repository.
